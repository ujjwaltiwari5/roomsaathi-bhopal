# RoomSaathi Bhopal 🏠

RoomSaathi Bhopal is a Bhopal-focused platform where property owners list rooms/flats for rent, and students & professionals search by area and contact owners directly on WhatsApp.

## Features
- Area-wise room/flat search (MP Nagar, Kolar Road, Arera Colony, etc.)
- Filter by room type, preferred tenants
- Listing creation with photo upload (Cloudinary)
- User authentication
- Reviews & ratings
- Direct WhatsApp contact with owner
- Map integration for listing location

## Tech Stack
- Node.js, Express.js
- MongoDB, Mongoose
- EJS, ejs-mate
- Bootstrap 5
- Cloudinary (image storage)
- Passport.js (auth)
